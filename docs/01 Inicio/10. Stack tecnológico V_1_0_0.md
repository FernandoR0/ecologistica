## 2. Justificación Técnica Formal

| Capa | Tecnología | Versión | Justificación |
|---|---|---|---|
| Frontend | React + Vite + TypeScript | 19 / 6 / 5.8 | SPA rápida con tipado estático; carga diferida por pantalla (Green IT) |
| Mapa | Leaflet + OpenStreetMap | 1.9 | Libre, sin costo de licencias (restricción C-03) |
| Backend | Python + FastAPI | 3.12 / 0.162 | Validación automática con Pydantic y documentación Swagger en `/docs` |
| Motor de rutas | Google OR-Tools | 9.12 | Solver VRPTW probado industrialmente; incluye la metaheurística de Búsqueda Tabú |
| ORM | SQLAlchemy | 2.0 | Independiente del motor de base de datos; SQLite en pruebas y PostgreSQL en producción |
| Base de datos | PostgreSQL | 16 | Robusta y con soporte geoespacial (PostGIS) si se necesita |
| Seguridad | PyJWT + bcrypt | 2.15 / 4.3 | Estándares de la industria para sesión y contraseñas |
| Pruebas | pytest, Vitest, Testing Library, Playwright | - | Pruebas unitarias, de integración y E2E |
| Calidad | Ruff, ESLint, SonarQube Cloud, Lighthouse, axe-core | - | Análisis estático, seguridad, accesibilidad y rendimiento |
| DevOps | Docker Compose, GitHub Actions | - | Entorno reproducible y CI en cada push |
