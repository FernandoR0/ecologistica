---

| Capa | Tecnología | Justificación |
|---|---|---|
| Frontend | React 19 + Vite + TypeScript | SPA rápida, tipado estático |
| Mapa | Leaflet + OpenStreetMap | Libre, sin costo de licencias |
| Backend | Python 3.12 + FastAPI | Validación automática (Pydantic) y documentación Swagger en `/docs` |
| Motor de rutas | Google OR-Tools | Solver VRPTW probado industrialmente (capacidad, ventanas, multi-vehículo) |
| ORM | SQLAlchemy 2 | Independiente del motor de BD |
| Base de datos | PostgreSQL 16 | Robusta, compatible con PostGIS si se requiere |
| Seguridad | PyJWT + bcrypt | Estándares de la industria |
| Pruebas | pytest, Vitest, Testing Library | Unitarias e integración |
| Calidad | Ruff, ESLint, SonarQube, Lighthouse | Análisis estático, accesibilidad y desempeño |
| DevOps | Docker Compose, GitHub Actions | Entorno reproducible y CI |
