## 1. Propósito
Construir una plataforma web que genere rutas de reparto optimizadas (VRPTW + Green VRP) para DistriRápido S.A.C.,
reduciendo distancia, tiempo y emisiones de CO₂ y cumpliendo las ventanas horarias de los clientes.

## 2. Objetivos medibles

| # | Objetivo | Indicador | Meta |
|---|---|---|---|
| O1 | Reducir la distancia recorrida | km optimizados vs. ruta manual | ≥ 20 % menos |
| O2 | Reducir emisiones | kg CO₂ por entrega | ≥ 15 % menos |
| O3 | Cumplir horarios | % entregas dentro de su ventana | ≥ 95 % |
| O4 | Tiempo de cálculo | generación de rutas para 150 pedidos / 15 vehículos | ≤ 45 s |
| O5 | Usabilidad | puntaje SUS | ≥ 70 |

## 3. Alcance
**Incluye:** RF-001 a RF-010 (ver `06. Requisitos funcionales`), roles ADMIN / PLANIFICADOR / CONDUCTOR,
despliegue con Docker.
**No incluye:** facturación, rastreo GPS en tiempo real del vehículo, app móvil nativa.
