---

| ID | Regla |
|---|---|
| RN-01 | Un vehículo no puede transportar más peso que su capacidad declarada. |
| RN-02 | Cada entrega debe ocurrir dentro de la ventana horaria del pedido. |
| RN-03 | Si el cliente tiene una preferencia de recepción para ese día, la ventana efectiva es la intersección entre la ventana del pedido y la preferencia. |
| RN-04 | La duración de una ruta no puede superar la jornada máxima del conductor (por defecto 480 min). |
| RN-05 | Solo se planifican vehículos activos con un conductor activo asignado. |
| RN-06 | Los pedidos que no caben en ninguna ruta factible se informan como "no asignados"; los de prioridad alta se penalizan más al descartarse. |
| RN-07 | Un pedido PLANIFICADO no puede modificarse; para cambiarlo se re-optimiza la ruta. |
| RN-08 | Las bajas son lógicas (vehículos y conductores se desactivan; pedidos se cancelan) para conservar historial. |
| RN-09 | El CO₂ de una ruta = distancia × consumo/100 × factor de emisión del combustible. |
| RN-10 | Ante una avería, las paradas pendientes se reasignan solo a vehículos que no tengan otra ruta vigente ese día. |
