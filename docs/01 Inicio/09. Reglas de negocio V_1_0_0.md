## 1. Codificación de Reglas de Negocio

| ID | Regla |
|---|---|
| RN-01 | Un vehículo no puede transportar más peso que su capacidad declarada. |
| RN-02 | Cada entrega debe ocurrir dentro de la ventana horaria del pedido. |
| RN-03 | Si el cliente tiene preferencia para ese día, la ventana efectiva es la intersección entre la ventana del pedido y la preferencia. |
| RN-04 | La duración de una ruta no supera la jornada máxima del conductor (480 min por defecto). |
| RN-05 | Solo se planifican vehículos activos con un conductor activo asignado. |
| RN-06 | Los pedidos que no caben en ninguna ruta se informan como no asignados; los de prioridad alta se penalizan más al descartarse. |
| RN-07 | Un pedido PLANIFICADO no se puede editar; para cambiarlo se re-optimiza la ruta. |
| RN-08 | Las bajas son lógicas: vehículos y conductores se desactivan y los pedidos se cancelan. |
| RN-09 | CO₂ de una ruta = km × consumo / 100 × factor de emisión del combustible. |
| RN-10 | Ante una avería, las paradas pendientes solo se reasignan a vehículos sin otra ruta vigente ese día. |
| RN-11 | La placa del vehículo y el DNI del conductor son únicos. |
| RN-12 | Cinco intentos fallidos de inicio de sesión bloquean la cuenta 15 minutos. |
