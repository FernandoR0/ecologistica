## 1. Criterio de especificación

Cada atributo de calidad se expresa como un **escenario de calidad de seis componentes** (arc42 / ISO/IEC 25010):
Fuente → Estímulo → Entorno → Artefacto → Respuesta → Medida. Todas las medidas tienen un umbral numérico verificable y
la herramienta con la que se comprueban.

## 2. Escenarios de Calidad

| ID | Categoría ISO 25010 | Escenario de Calidad (Fuente -> Estímulo -> Entorno -> Artefacto -> Respuesta -> Medida SLA) |
|---|---|---|
| RNF-001 | Eficiencia de desempeño - Comportamiento temporal | **Fuente:** Planificador. **Estímulo:** Pulsa "Generar rutas optimizadas" con 150 pedidos y 15 vehículos. **Entorno:** Operación normal en producción. **Artefacto:** Motor VRPTW + Green VRP (Búsqueda Tabú). **Respuesta:** Devuelve un plan factible y lo persiste. **Medida:** Tiempo ≤ 45 s en el percentil 95 de 5 ejecuciones (script de prueba de carga). |
| RNF-002 | Eficiencia de desempeño - Comportamiento temporal | **Fuente:** Planificador. **Estímulo:** Registra un incidente sobre una ruta en curso. **Entorno:** Hora punta (7:00-9:00 o 17:00-20:00). **Artefacto:** Servicio de re-optimización. **Respuesta:** Genera la nueva versión de la ruta con las paradas pendientes. **Medida:** Tiempo ≤ 30 s en el percentil 95. |
| RNF-003 | Eficiencia de desempeño - Comportamiento temporal | **Fuente:** Usuario autenticado. **Estímulo:** Abre un listado (pedidos, flota, conductores, clientes). **Entorno:** Producción con 1 000 pedidos registrados. **Artefacto:** API REST. **Respuesta:** Devuelve la página de 12 registros. **Medida:** Latencia ≤ 500 ms en el P95 medida con Playwright; LCP ≤ 1,4 s y peso de página ≤ 1,1 MB en Lighthouse (escritorio). |
| RNF-004 | Seguridad - Confidencialidad e integridad | **Fuente:** Atacante externo. **Estímulo:** Intento de inyección SQL, XSS o acceso sin token a un endpoint protegido. **Entorno:** Producción. **Artefacto:** API FastAPI con ORM, validación Pydantic y JWT. **Respuesta:** Rechaza la petición (401/403/422) sin ejecutar la entrada y la registra en la auditoría. **Medida:** 0 vulnerabilidades críticas o altas del OWASP Top 10 en SonarQube Cloud y 0 vulnerabilidades en `pip-audit` y `npm audit` de producción. |
| RNF-005 | Seguridad - Autenticidad y responsabilidad | **Fuente:** Usuario o atacante. **Estímulo:** 3 intentos de acceso fallidos seguidos. **Entorno:** Producción. **Artefacto:** Módulo de autenticación. **Respuesta:** Bloquea la cuenta y registra el evento con fecha, correo y código HTTP. **Medida:** Bloqueo de 15 min tras el tercer intento; 100 % de las operaciones de escritura con registro de auditoría; contraseñas con bcrypt (costo ≥ 12). |
| RNF-006 | Fiabilidad - Disponibilidad | **Fuente:** Infraestructura en la nube. **Estímulo:** Reinicio o suspensión del servicio de la API. **Entorno:** Horario operativo 5:00-22:00. **Artefacto:** API, base de datos PostgreSQL y frontend estático. **Respuesta:** El servicio se recupera automáticamente y el frontend muestra un mensaje de indisponibilidad mientras tanto. **Medida:** Disponibilidad ≥ 99,5 % mensual en horario operativo; RTO ≤ 60 s; RPO ≤ 24 h (respaldo diario de la base). |
| RNF-007 | Usabilidad - Accesibilidad | **Fuente:** Usuario con discapacidad visual o motriz. **Estímulo:** Navega con teclado y lector de pantalla. **Entorno:** Navegador de escritorio o móvil. **Artefacto:** Interfaz React. **Respuesta:** Todas las funciones son operables y anunciadas. **Medida:** 0 violaciones WCAG 2.1 AA con axe-core en las 8 pantallas; contraste ≥ 4,5:1; accesibilidad ≥ 90 en Lighthouse. |
| RNF-008 | Usabilidad - Facilidad de aprendizaje | **Fuente:** Conductor con educación básica. **Estímulo:** Usa el sistema por primera vez. **Entorno:** Celular. **Artefacto:** Modo conductor. **Respuesta:** Identifica su siguiente entrega sin ayuda. **Medida:** Puntaje SUS promedio ≥ 68 con n ≥ 5 usuarios; tareas críticas completadas sin ayuda ≥ 80 %. |
| RNF-009 | Capacidad / Escalabilidad | **Fuente:** Crecimiento de la empresa. **Estímulo:** 1 000 pedidos diarios y 50 vehículos. **Entorno:** Producción. **Artefacto:** API sin estado en contenedores y base PostgreSQL. **Respuesta:** Se agrega una réplica de la API sin cambiar código. **Medida:** Listados paginados con tamaño de respuesta constante (≤ 15 KB por página); la API escala horizontalmente a 2 réplicas en ≤ 5 min. |
| RNF-010 | Mantenibilidad - Analizabilidad y capacidad de prueba | **Fuente:** Desarrollador. **Estímulo:** Integra un cambio a `main`. **Entorno:** GitHub Actions. **Artefacto:** Código backend y frontend. **Respuesta:** El pipeline ejecuta lint, pruebas y análisis estático. **Medida:** Cobertura ≥ 80 %, duplicación ≤ 3 %, Quality Gate PASSED; pipeline ≤ 15 min. |
| RNF-011 | Portabilidad - Instalabilidad | **Fuente:** Operador de TI. **Estímulo:** Despliega una nueva versión. **Entorno:** Docker o servicio PaaS. **Artefacto:** Imágenes Docker y workflow de despliegue. **Respuesta:** Publica la versión etiquetada sin pasos manuales. **Medida:** Despliegue automático tras push a `main` o tag `v*` en ≤ 10 min. |
| RNF-012 | Compatibilidad / Eco-diseño (Green Software) | **Fuente:** Visitante. **Estímulo:** Carga la pantalla de acceso. **Entorno:** Red móvil 4G. **Artefacto:** Frontend compilado. **Respuesta:** Entrega recursos comprimidos y cacheables. **Medida:** Peso transferido ≤ 1,1 MB; emisiones ≤ 0,05 g CO₂e por visita según Sustainable Web Design Model v4. |
